# Getting Started

⚠️ ***Important Upgrade Notice***
When updating to the latest Timeflow package, *please first remove the old installation* for a clean install. Otherwise compile errors may occur if older files or directory structures are still in place. 

Backing up your project before modification is recommended. To remove the installation you may simply delete the AxonGenesis folder, or move it outside of the Assets directory.

# Welcome to Timeflow!

Timeflow is an animation system designed to meet the needs of both artists and developers. With an emphasis on motion graphics, cutscenes, and music synchronization, Timeflow offers advanced curve editing tools, procedural animations, and dynamic behaviors which can be used alongside Unity Timeline or independently. 

Easily add new animations and procedural behaviors to any object or property. The integrated track-based timeline view provides an intuitive interface that includes rich editing and creative features, allowing you to animate anything from individual elements to choreographing entire scenes in any type of Unity project.


👉 To open the Timeflow view in the Unity Editor use the keyboard shortcut Control + Shift + Alt + T, or select from the main menu:
Tools/Timeflow/Open Timeflow Window


✅ **Render Pipelines**
Timeflow fully supports all render pipelines including built-in, URP, HDRP, and Custom RP.  Any pipeline may be used and samples are included for each, however URP is generally recommended for balanced performance and features.


📖 Samples

Timeflow includes example scenes and a buildable demo app. The examples by default use the built-in render pipeline. For use with either the Universal Render Pipeline (URP) or the High Definition Render Pipeline (HDRP) please import one of the included packages.


🕹️ **Demo App**
To view the main demo, locate and open the scene DemoAppMain. 

*Before entering play mode, be sure to configure the Build Settings to include the requisite scenes. For further information, please refer to the [demo app documentation](https://axongenesis.gitbook.io/timeflow/reference/examples/demo-app).*
